# TBC-GetData-FinalProject
Final project for data analytics course (TBC-GetData)

### 1. ნედლი ცხრილის შექმნა CSV ფაილიდან (`00_creating_raw_table_from_csv`)
`motogp_dataset_v2.csv` ფაილიდან მონაცემები ატვირთვისას ზუსტად გავწერე შესაბამისი ტიპებით `getdata.raw.MotogpTest` სქემაში, რათა უზრუნველყოფილიყო თითოეული სვეტის სტრუქტურული მთლიანობა:
* `SpeedKmH` (`DECIMAL(10,2)`): მოტოციკლის სიჩქარე კმ/სთ-ში (მაგ: `200.06`).
* `CornerRadiusM` (`DECIMAL(10,2)`): მოსახვევის რადიუსი მეტრებში (მაგ: `42.54`).
* `TrackGrip` (`DECIMAL(10,4)`): ტრასის მოჭიდების ინდექსი / mu (μ) (მაგ: `1.0257`).
* `BikeMassKg` (`DECIMAL(10,2)`): მოტოციკლის მასა კილოგრამებში (მაგ: `150.75`).
* `TrackTemperature` (`DECIMAL(10,2)`): ტრასის ტემპერატურა გრადუს ცელსიუსში (მაგ: `43.52`).
* `TrackBankingDeg` (`DECIMAL(10,2)`): ტრასის დახრილობის კუთხე გრადუსებში (მაგ: `2.76`).
* `TireType` (`STRING`): საბურავის ტიპი (მაგ: `hard`).
* `LeanAngleDeg` (`DECIMAL(10,2)`): რეალური გადახრის კუთხე გრადუსებში (მაგ: `65.00`).

### 2. ნოუთბუქის ლოგიკა (`Motogp_Test_dashboard_მონაცემების_ტრანსფორმაცია`)
ნოუთბუქით ვკითხულობ `getdata.raw.MotogpTest` ცხრილს, ვამუშავებ მას და ვინახავ `getdata.calculated.MotogpTest` ცხრილში დეშბორდისთვის საჭირო დამატებითი გამოთვლებითა და კატეგორიზაციით:

* **ფიზიკური გამოთვლები (Feature Engineering):**
  * ვთვლი თეორიულ გადახრის კუთხეს ფორმულით:
    $$\tan(\theta) = \frac{v^2}{g \times r}$$
    *(მაქსიმალური ზედა ზღვრით 68°)*.
  * ვთვლი ცენტრისკენულ აჩქარებას ფორმულით:
    $$a_c = \frac{v^2}{r}$$

* **მონაცემთა კატეგორიზაცია:**
  * `CornerType`: მოსახვევის ტიპი (მკვეთრი < 80მ, საშუალო 80-150მ, ფართო > 150მ).
  * `TemperatureZone`: ტემპერატურული ზონა (გრილი < 30°C, ოპტიმალური 30-40°C, ცხელი > 40°C).
  * `TrackInclination`: ტრასის დახრილობა (დაღმართი < 0°, ბრტყელი 0-4°, აღმართი > 4°).
  * `GripLevel`: მოჭიდების დონე (დაბალი < 0.85, საშუალო 0.85-0.95, მაღალი > 0.95).

### 3. დეშბორდის მონაცემთა შერჩევა და მორგებული მეტრიკები
* **მონაცემთა შერჩევა და ფილტრაცია:** 
  ანალიზისთვის გამოიყენება `getdata.calculated.MotogpTest` ცხრილი. ამ ეტაპზე მონაცემები იფილტრება პარამეტრ `MinAngle`-ის მეშვეობით, რომელიც ადგენს გადახრის კუთხის მინიმალურ ზღვარს (საწყისი მნიშვნელობით 30°), ხოლო საბურავის ტიპები (`TireTypeGeo`) `CASE` ოპერატორის გამოყენებით ითარგმნება ქართულად (`რბილი`, `საშუალო`, `მაგარი`).

* **მორგებული მეტრიკები (Custom Measures):**
  * **მაღალი რისკის ჩანაწერები:** ითვლის 50°-ზე მეტი გადახრის კუთხის მქონე წერტილებს (> 50).
  * **მაღალი ტემპერატურის საშუალო სიჩქარე:** გამოთვლის საშუალო სიჩქარეს ცხელ ზონაში (> 40°C).
  * **დაბალი ტემპერატურის საშუალო სიჩქარე:** გამოთვლის საშუალო სიჩქარეს გრილ ზონაში (<= 30°C).
  * **საშუალო ტემპერატურის საშუალო სიჩქარე:** გამოთვლის საშუალო სიჩქარეს ოპტიმალურ ტემპერატურულ ზონაში (30°C - 40°C).
  * **საშუალო არითმეტიკული თეორიული და რეალური გადახრის კუთხეების სხვაობის:** ზომავს საშუალო სხვაობას თეორიულ და ფაქტობრივ გადახრის კუთხეებს შორის.

* **თეორიული მოტოციკლის დახრის კუთხე:** ჯგუფდება 5-გრადუსიანი ნაბიჯებით.
* **მოტოციკლის მასა:** ჯგუფდება 5-კილოგრამიანი ნაბიჯებით.
